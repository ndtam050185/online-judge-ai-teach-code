📌 BƯỚC 2: Đẩy dự án lên GitHub
Render lấy mã nguồn trực tiếp từ GitHub, nên bạn cần đẩy dự án lên một kho chứa (Repository) trên GitHub trước:

1. Đăng nhập vào GitHub.com (Tạo tài khoản nếu chưa có).

2. Tải và cài đặt Git trên máy tính nếu chưa cài.

3. Tạo một Repository mới trên GitHub:

Nhấn nút New (hoặc dấu + ở góc trên bên phải).

Đặt tên kho chứa (VD: online-judge-ai).

Chọn trạng thái Private (Riêng tư) hoặc Public.

Nhấn Create repository.

4. Mở Terminal (hoặc Command Prompt / Git Bash) tại thư mục dự án trên máy tính và chạy lần lượt các lệnh sau:
git init
git add .
git commit -m "Khoi tao du an Online Judge"
git branch -M main
git remote add origin https://github.com/Tên_Tài_Khoản_GitHub/online-judge-ai.git
git push -u origin main

📌 BƯỚC 3: Triển khai web lên Render.comTruy cập trang web Render.com và tạo tài khoản 
(nên dùng nút Sign in with GitHub để liên kết trực tiếp).Sau khi đăng nhập, tại Bảng điều khiển (Dashboard), 
nhấn nút New + ở góc phải và chọn Web Service.Chọn tùy chọn Build and deploy from a Git repository $\rightarrow$ 
Nhấn Next.Tìm đến tên Repository online-judge-ai của bạn vừa đẩy lên GitHub và nhấn Connect.Cấu hình các thông số 
trên trang cài đặt Render:Name: Đặt tên cho Web (VD: my-online-judge — Tên này sẽ làm tên miền web của bạn).
Language: Chọn Node.Branch: Chọn main.Region: Chọn Singapore (để tốc độ về Việt Nam nhanh nhất).Build Command: 
Điền npm install.Start Command: Điền npm start (hoặc node server.js).Instance Type: Chọn gói Free ($0/month).
